# Crédito imobiliário | Comparação de classificadores

Experimentos de classificação e balanceamento para estimar probabilidade de inadimplência em crédito imobiliário.

**Machine learning** · Projeto de curso em equipe

[← Portfólio de Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Comparar estratégias de modelagem usando métricas de classificação, incluindo ROC-AUC, no cenário do exercício.

## O que você encontra

- Preparação dos dados e separação das bases.
- Experimentos com classificadores e técnicas de balanceamento.
- Avaliação por métricas e busca de configurações de modelos.

## Tecnologias

Python · pandas · scikit-learn · imbalanced-learn · XGBoost
